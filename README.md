# DenTag

Android向けのMP3・FLACタグ編集アプリの配布用リポジトリです。

[最新版のAPKはこちら](https://github.com/denngaku-chan/DenTag-Release/releases/latest)

曲名・アーティスト・アルバム名・トラック番号・発売年・ジャンルとジャケット画像を編集できます。音声の切り貼り・再圧縮は行いません。

保存時は「元の曲に上書き」と「編集したコピーを保存」を選べます。Android 8.0以上に対応しています。

## v1.0.2：音量補正（ReplayGain）

「音量補正」の欄で、曲ごとの再生音量を指定できます。マイナスで小さく、プラスで大きく、0で補正なし、空欄・解除で曲単位の音量補正タグを削除します。「-1 dB」「+1 dB」ボタンでも調整できます。

音声データは変更しません。対応する音楽プレイヤーでReplayGainを有効にし、曲単位（トラック）を選んでください。

APKをダウンロードしてインストールしてください。既存版と同じ署名のため、上書きインストールできます。

公開用ソースには署名鍵を含めていません。合計76ケースを検証済みですが、実機での画面操作・プレイヤーでの音量反映は未確認です。
