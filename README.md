# DenTag

Android向けのMP3・FLACタグ編集アプリの配布用リポジトリです。

[最新版のAPKはこちら](https://github.com/denngaku-chan/DenTag-Release/releases/latest)

曲名・アーティスト・アルバム名・トラック番号・発売年・ジャンルとジャケット画像を編集できます。音声の切り貼り・再圧縮は行いません。

保存時は「元の曲に上書き」と「編集したコピーを保存」を選べます。Android 8.0以上に対応しています。

APKをダウンロードしてインストールしてください。v1.0.1は初版と同じ署名のため、上書きインストールできます。

公開用ソースには署名鍵を含めていません。
