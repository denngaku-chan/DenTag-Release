# DenTag v1.1.0 UI更新版

UIのみの更新です。音声処理、MP3Gain、ReplayGain、タグ編集、保存処理のロジックは変更していません。

## 変更点

- 右上の緑色の「曲を選ぶ」ボタンを削除しました。
- 「まずは曲を選んでください」のカード全体をタップして曲を選べるようにしました。曲を開いたあとも、このカードから別の曲に切り替えられます。未保存の変更がある場合の確認と、処理中の操作制限は維持しています。
- MP3Gain画面下部の「元に戻す（Undo）」と「変更予約を解除」をまとめました。
- 「キャンセル」と「設定を使って戻る」を画面下に固定し、保存方法の説明をカードに整理しました。ライセンスはリンク風の操作として残しています。

## 配布ファイル

- `DenTag-v1.1.0-ui.apk`：同じ配布用の鍵で署名したUI更新版APK。
- `DenTag-v1.1.0-ui-source-public.zip`：更新ソースとライセンス。署名鍵・署名用パスワードを含みません。
- `ui-changes.patch`：今回変更した2つのUI Activityの差分。
- `SHA256SUMS`：上記ファイルのSHA-256。

APK内のバージョン情報は引き続き1.1.0（versionCode 4）です。ファイル名の `ui` は今回のUI更新を区別するための表記です。

- APKビルド、ZIPアラインメント、v2／v3署名検証：成功。
