# DenTag v1.1.1

保存中にフォントサイズ変更などで画面が再生成されると、古い画面の完了処理が新しい画面の作業ファイルを削除し、編集を続けられなくなる不具合を修正しました。破棄済み画面への完了ダイアログ表示も防ぎます。

保存処理を画面から分離し、再生成した画面に処理と結果を引き継ぎます。保存中は操作を制限し、完了後は同じ曲への上書き保存を続けられます。コピー保存、保存失敗時の編集内容の維持、保管した元データの取り出しも確認しています。

曲選択カードとMP3Gain画面下部のUI更新を含みます。既存版と同じ署名鍵で署名しているため、そのまま上書きインストールできます。Android 8.0以上に対応し、versionCodeは5です。

検証結果:

- 既存の処理系232件が成功。
- RobolectricによるAndroid API 26・35の画面・保存テスト22件が成功。画面再生成、状態保存直後の完了、連続した再生成、続けて上書き保存、バックグラウンドからの再開、コピー保存、保存失敗、元データの取り出しを含みます。
- APKのパッケージ・バージョン・API設定、zipalign、v2/v3署名、既存版との署名一致を確認。

実機での表示、端末固有のMediaCodecによる音量解析、実際のSAFプロバイダー経由の保存は未確認です。

配布物は署名済みAPK、再発防止テストを含む公開用ソース、修正差分、検証結果、SHA-256一覧です。公開用ソースには配布用の署名鍵・パスワードを含めていません。
